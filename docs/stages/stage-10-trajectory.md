# 阶段 10：轨迹记录

## 阶段目标

保存 prompt、工具调用、diff、测试结果和关键决策，方便复盘、调试和评测。

## 要学习的问题

- Agent 轨迹应该记录什么？
- 哪些内容可能包含隐私或密钥？
- 轨迹记录应该面向人读，还是面向程序分析？
- 如何避免日志过大？
- 如何用轨迹帮助评测？

## 理论要点

- 没有轨迹，就很难知道 Agent 为什么做出某个动作。
- 轨迹是评测、复盘和改进 prompt 的基础。
- 轨迹需要脱敏和大小控制。

## 开发范围

- 轨迹数据结构。
- prompt 和消息记录。
- 工具调用记录。
- diff 和测试结果记录。
- 轨迹保存路径。
- 简单脱敏规则。

## 暂时不做什么

- 可视化分析平台。
- 大规模遥测系统。
- 云端同步。
