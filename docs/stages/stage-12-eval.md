# 阶段 12：评测系统

## 阶段目标

用任务集、指标和失败归因评估 Agent 能力，让改进不只靠主观感觉。

## 要学习的问题

- Agent 应该怎么评测？
- 什么是任务完成率？
- 工具调用正确率怎么衡量？
- 如何评估安全边界？
- 失败归因应该怎么分类？

## 理论要点

- Agent 评测要看最终结果，也要看过程轨迹。
- 同一个任务需要可重复运行。
- 失败类型比单一分数更能指导改进。

## 开发范围

- 小任务集。
- 运行器。
- 成功率统计。
- 工具调用统计。
- 失败归因。
- 简单报告。

## 暂时不做什么

- 大规模 benchmark。
- 自动线上监控。
- 多模型排行榜。
