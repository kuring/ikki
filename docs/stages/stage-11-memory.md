# 阶段 11：记忆系统

## 阶段目标

让 Agent 能保存用户偏好、项目约定和历史摘要，并在合适的时候重新使用。

## 要学习的问题

- Memory 和普通会话历史有什么区别？
- 什么信息值得长期保存？
- 记忆什么时候会过期？
- 如何避免错误记忆影响后续任务？
- 用户如何查看、修改或删除记忆？

## 理论要点

- 记忆是长期协作能力，不是把所有历史都塞进上下文。
- 好的记忆需要来源、时间、适用范围和置信度。
- 用户应该能控制记忆。

## 开发范围

- 用户偏好记忆。
- 项目约定记忆。
- 历史任务摘要。
- 记忆检索。
- 记忆更新和删除。

## 暂时不做什么

- 复杂向量数据库。
- 自动永久保存所有内容。
- 跨用户共享记忆。

## 实现任务

- [ ] 定义记忆条目结构。
- [ ] 保存用户偏好。
- [ ] 保存项目约定。
- [ ] 在任务开始时检索相关记忆。
- [ ] 支持用户查看和删除记忆。
- [ ] 标记记忆来源和更新时间。

## 完成标准

- [ ] Agent 能记住一条用户偏好。
- [ ] Agent 能在相关任务中使用记忆。
- [ ] 用户能查看和删除记忆。
- [ ] 打 tag：`v1.1-memory`。

## 复盘问题

- 记忆冲突时如何处理？
- 记忆检索失败会造成什么问题？
