# 阶段 2：最小 Tool Calling

## 阶段目标

让 Agent 从“会回答”变成“会调用工具”，先跑通最小工具选择、参数生成、执行和结果回填流程。

## 要学习的问题

- Tool Calling 是什么？
- 工具 schema 为什么要结构化？
- 工具参数如何校验？
- 工具执行失败后，应该如何把错误返回给模型？
- 工具结果应该原样回填，还是先做包装？
- 工具权限边界应该从什么时候开始设计？

## 理论要点

- 工具是模型接触外部世界的接口，schema 越清楚，调用越稳定。
- 工具错误是正常路径的一部分，不应该直接让程序崩溃。
- 工具调用日志是后续复盘和评测的重要证据。

## 开发范围

- 工具注册表。
- `get_time` 工具。
- `calculator` 工具。
- `read_file` 工具。
- 工具参数校验。
- 工具调用日志。

## 暂时不做什么

- shell 命令执行。
- 文件编辑。
- 浏览器操作。
- 复杂工具权限系统。
