# 阶段 3：代码仓库感知

## 阶段目标

让 Agent 能理解一个本地代码仓库的基本结构，能够搜索文件、读取片段，并在回答中引用具体路径。

## 要学习的问题

- Coding Agent 为什么需要搜索，而不是一次性读完整仓库？
- 文件树、关键词搜索、文件片段读取分别解决什么问题？
- `.gitignore`、隐藏文件和大文件为什么需要处理？
- 如何限制 Agent 只能读取工作区内的文件？
- 回答中如何引用证据路径？

## 理论要点

- 仓库感知的核心不是“读得多”，而是“找得准”。
- `rg` 这类搜索工具比全量读取更适合真实代码仓库。
- 工作区边界是安全能力的一部分。

## 开发范围

- `list_files` 工具。
- `search_text` 工具，优先使用 `rg`。
- `read_file_range` 工具。
- 工作区根目录限制。
- 回答中的文件路径引用。

## 暂时不做什么

- 文件编辑。
- shell 命令执行。
- 自动修复代码。
- 跨仓库搜索。
